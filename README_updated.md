# 🎬 Netflix Data Analysis | Power BI Dashboard

## 📌 Project Overview
This project focuses on analyzing Netflix content using Microsoft Power BI. The dashboard helps explore the distribution of movies and TV shows, content ratings, genres, countries, and release trends.

## 🎯 Project Objectives
- Analyze the distribution of Movies and TV Shows.
- Identify popular content genres.
- Explore content availability across different countries.
- Analyze content ratings and release-year trends.
- Present key findings through interactive visualizations.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning and Transformation
- Data Visualization

## 🔍 Key Analysis Areas
- Movies vs. TV Shows distribution
- Content by genre and category
- Country-wise content distribution
- Ratings analysis
- Release-year trends

## 📊 Dashboard
The interactive Power BI dashboard provides visual insights into Netflix's content library through charts, KPI cards, and filters.

- Data Modeling

## 🎯 Project Outcome
Developed an interactive dashboard to transform raw Netflix data into meaningful insights and support data-driven analysis.
